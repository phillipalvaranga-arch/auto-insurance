# Auto Insurance Finder

Installable web app for comparing Texas car insurance (Frisco, TX 75034): published average prices with sources and dates, J.D. Power 2026 Texas scores, AM Best and NAIC complaint data, delivery-driver coverage notes, official quote links, a private quote tracker (saved on the device only), savings checklist and plain-English coverage guide.

- Live: https://phillipalvaranga-arch.github.io/auto-insurance/
- `data/insurers.json`: curated, sourced numbers. "n/a" = not verified.
- `data/status.json`: written daily by `.github/workflows/status.yml` (website reachability + whether rate sources published a newer update).

Information only. Not insurance advice. Never collects SSN, driver's license number, full VIN, bank/card numbers or passwords.
